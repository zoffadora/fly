# 🪰 Проучи муху

Игра на Python с использованием Tkinter, где нужно бить мухобойкой летающую муху за ограниченное время.

## 🎮 Управление
- **Движение мыши** — перемещение мухобойки
- **ЛКМ (зажать)** — удар мухобойкой
- **ЛКМ (отпустить)** — возврат в исходное положение

## 🎯 Цель игры
Попасть мухобойкой по летающей мухе, чтобы заработать очки. Каждое попадание приносит **+1 очко**.

## ⏱️ Таймер
Игра длится **20 секунд**. После окончания времени выводится результат с эмоциональной оценкой:
- **0–7 очков** — "Ты можешь лучше!" (грустный смайл)
- **8–19 очков** — "Хороший результат!" (лайк)
- **20+ очков** — "Отличный результат!" (весёлый смайл)

## 🦟 Механика мухи
- Муха движется по экрану, отскакивая от границ
- Скорость и направление случайные (от 1 до 5 с коэффициентом ±1)
- Муха автоматически телепортируется в случайное место каждую секунду
- Телепортация не происходит близко к мухобойке (избегание мгновенного удара)
